## Current Research Overview 👋


As a PhD student in Artificial Intelligence, my current research focuses on developing a hybrid deep-learning model for analyzing chest X-ray (CXR) images of patients diagnosed with tuberculosis.
The goal is to improve diagnostic accuracy and provide more reliable decision-support tools for early detection and treatment planning.

This work uses multiple publicly available datasets and applies a full pipeline of data preprocessing, noise reduction, and data augmentation using an improved DCGAN.
The proposed hybrid model incorporates Vision Transformers (ViT) for feature extraction, and results are interpreted using Explainable AI (XAI) methods such as heatmap-based visualizations.

Includes TB and Normal chest X-rays used for binary classification tasks.
